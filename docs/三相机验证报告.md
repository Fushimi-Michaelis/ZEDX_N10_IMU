## 三路采集

```bash
python3 scripts/capture_remote_n10.py record --initialize --name 20261101-pruned-three --frames 600 --save-every 60
```

每路预热 90 帧，再接收 600 帧，每 60 帧保存一组，逐帧时间戳全部保留；三路同时接收时间重叠 11.26 秒。

## 官方 RGB-D

10 张实时样本有效深度比例 **62.30%–63.84%**。最后一张有效比例 62.30%，有效深度中位数 0.382 m。

最后一张有 673 对可靠匹配，正视差比例 99.85%，垂直残差中位数 0.274 px。629 个有效特征点的 SDK 深度与 `fx × baseline / disparity` 相比，中位绝对差 0.715 mm、中位相对差 0.185%。这是内部几何一致性检查，不是实物测距精度。

RGB 与深度来自同一次 SDK `grab()`，保存校正 RGB、float32 米制深度和置信度，没有填洞。

## 验证边界

SHW 是单目 RGB，不各自产生深度。SHW 保存 JPEG 时存在接收间隔增大，未验收无丢帧全帧录像。绝对距离精度和三机曝光同步未标定；SHW 传感器与 SDK 图像时间戳不能直接相减。正常逐路启停通过，不代表全局驱动重载互不影响。
